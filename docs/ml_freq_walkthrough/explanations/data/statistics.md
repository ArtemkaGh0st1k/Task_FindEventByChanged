## @module  [906d0e39]
Читатели **основного** набора 2021–2026: объединённой статистики `Статистика_с_2021_2026_в_одном_файле.xlsx` (лист на параметр, строка — скважина, столбцы — даты 01.01.2020–31.12.2026) и итогового файла технологов `Итоговый_файл_c_2021_2026.xlsx` (лист «Лист1», строка — мероприятие, 786 строк).

Статистику склеил макрос, и часть выгрузок записана со сдвигом на 180 дней; модуль эти данные **не исправляет**, а читает «как есть» (только числа) и отдаёт в `repair.py`. Результат работы модуля — таблицы «скважина × дата» и список `LabelRecord`, которые `dataset.py` превращает в `WellSeries`.

### Пример
```python
from gtm_detector.ml_freq.data import MergedStatisticsReader, MonitoringLabelsReader
tables = MergedStatisticsReader(c.statistics).read()   # 6 таблиц, частота: 766 скважин × 2557 дат
records = MonitoringLabelsReader(c.labels).read()      # 786 записей
```
Сырая таблица ещё содержит сдвиг: у скважины 10335/988 ступенька частоты 49,5 → 50,5 → 51,5 Гц стоит на 10.02.2024, а технолог ставил начало 14.08.2023 (ровно 180 дней разницы).

## MergedStatisticsReader  [f6d2b4a1]
Читает файл статистики в словарь `{параметр: DataFrame}`. Строки таблицы — `MultiIndex(номер, куст)`, столбцы — `Timestamp` с 01.01.2020 по 31.12.2026 (2557 дат), значения — `float`. В ячейке годится **только число**: текст, даты и `bool` становятся `NaN`. Пустые столбцы в формате даты (2020 г., конец 2026 г.) pandas читает как `NaT` — это тоже пропуски. Счётчик заполненных, но не числовых ячеек по датам хранится в `non_numeric`.

### Пример
Листы файла: «Qж (из OIS)», «Обв (из OIS)», «Qн (из OIS)», «Рлин (из OIS)», «Fэцн ТМ(сут)», «Рзаб». Словарь `SHEETS` ищет лист по началу имени, поэтому суффиксы «(из OIS)» и «(сут)» не мешают.

## MergedStatisticsReader.read  [26dcfdae]
Читает шесть листов (`debit_liquid`, `watercut`, `debit_oil`, `pressure_line`, `frequency`, `pressure_zab`). Лист подбирается по префиксу после `normalize_id`: так латинская «F» в имени листа не помешает найти «Fэцн ТМ(сут)». Складывает вклад каждого листа в `non_numeric` (сумма по листам) и пишет в лог число скважин и дат. Возвращает словарь таблиц.

Таблицы разных параметров могут содержать разные наборы скважин: выравнивает их потом `dataset.py`.

### Пример
```python
tables = reader.read()
{k: v.shape for k, v in tables.items()}
# frequency: (766, 2557); debit_liquid, watercut, pressure_line, pressure_zab: (768, 2557); debit_oil: (767, 2557)
```

## MergedStatisticsReader._read_sheet  [04818b43]
Читает один лист целиком (`header=None`). Строка `HEADER_ROW = 1` — названия столбцов, данные начинаются со строки 3 (`HEADER_ROW + 2`: одна строка под шапкой — подзаголовок). Столбцы с датой в заголовке (настоящей или строкой `ДД.ММ.ГГГГ`) превращаются в числовые колонки через `_numbers`; столбцы «№ скв.» и «№ куста» находит `_position` и нормализует `normalize_id`. Строки без номера скважины и повторы пропускаются.

Возвращает пару: таблицу значений и `Series` «сколько ячеек по датам было заполнено, но не числом» (нужна для отчёта аудита).

### Пример
Если бы в листе «Fэцн ТМ(сут)» в дату 14.08.2023 стоял текст (например «ремонт»), он стал бы `NaN`, а в `non_numeric` за эту дату прибавилась бы 1. В текущем файле таких ячеек нет: `non_numeric.sum() == 0`.

## _header_date  [d495894f]
Определяет, дата ли в ячейке заголовка. Принимает значение ячейки; возвращает `Timestamp` для настоящей даты или строки `ДД.ММ.ГГГГ`, иначе `None` (заголовок «№ скв.», «Итого» и т. п. в календарь не входит).

### Пример
```python
_header_date('14.08.2023')            # Timestamp('2023-08-14')
_header_date(pd.NaT)                  # None
_header_date('№ скв.')                # None
```

## _position  [686dd052]
Номер столбца (с нуля) в строке заголовков, где написано ровно `title` (после `strip`). Нужен, чтобы не зависеть от того, что «№ скв.» стоит в таком-то по счёту столбце. Если столбца нет — `StopIteration`.

### Пример
`_position(header, "№ скв.")` — индекс столбца с номерами скважин; `_position(header, "№ куста")` — с кустами.

## _numbers  [cfa0e563]
Превращает столбец листа в массив `float` длиной в число скважин. Если pandas определил столбец как `bool` или дату — весь столбец `NaN` (пустой столбец в формате даты читается как `NaT`). Если тип числовой — берётся как есть. Смешанный столбец (число, текст, дата) обрабатывается по ячейкам через `_number`.

### Пример
Столбец из `[48.0, 'ремонт', datetime(2023, 8, 14)]` даст `[48.0, nan, nan]`.

## _number  [b405b42b]
Одна ячейка: настоящее число (`int`/`float`, в том числе NumPy) → `float`; `bool`, текст, дата → `NaN`. `bool` отдельно отсекается, потому что в Python `True` — это число 1.

### Пример
```python
_number(49.5)    # 49.5
_number("49,5")  # nan  (текст не пытаемся разбирать)
_number(True)    # nan
```

## LabelRecord  [1f1eb8c3]
Одна строка итогового файла технологов, ещё не проверенная замерами. Неизменяемый dataclass: `row` — номер строки в Excel (с шапкой, поэтому первая строка данных = 2), `number`, `cluster`, `kind` (тип ГТМ), `status`, `success` («да»/«нет»), `reason` (причина прекращения мониторинга), `start`/`end` (даты начала/окончания мониторинга), `current` и `new` — частота до и после мероприятия, **Гц**, `year`.

### Пример
Строка 307: скважина 10335, куст 988, «Изменение частоты, Гц», `current=49.5`, `new=49.96`, `start=2023-08-14`, `end=2023-09-20`, причина «прекращение эффекта по воде».

Пара `(number, cluster)` — ключ скважины для поиска в таблицах статистики.

## LabelRecord.censored  [7c479c7f]
`True`, если в причине прекращения мониторинга есть слово «продолжается» (регистр не важен). Тогда мониторинг остановили, а эффект шёл, и `end` — не конец эффекта; в `Interval` это превращается в `censored=True`, дни после него не обучают модель.

## MonitoringLabelsReader  [3e23641f]
Читает «Лист1» итогового файла: сводный список всех мероприятий. «Лист2» намеренно не читается: это частичная копия 2025 г., а строки, которых нет в «Лист1», — тип «Изменение ЦЭС/Частоты на увеличение», который технологи в сводный список не включили. `COLUMNS` — отображение заголовков Excel («Куст», «Скважина», «Тип ГТМ», «Статус ГТМ», «Успешно/Неуспешно», «Причина прекращения мониторинга», «дата начала мониторинга», «дата окончания мониторинга», «Текущее значение», «Новое значение», «Год») на поля `LabelRecord`. `EVENT_TYPES` — подходящие типы: «изменение частоты, гц» и «увеличение f».

### Пример
786 строк; после `rejection` (на уровне одной строки) остаётся 782: 3 строки с «новое ≤ текущего» и 1 «не выполнено». Остальные отказы (нет скважины, нет замеров, нет подъёма) определяются позже в `dataset.py`.

## MonitoringLabelsReader.read  [69405df7]
Читает «Лист1», оставляет нужные столбцы, переименовывает и строит `list[LabelRecord]` в порядке строк файла. Даты разбирает `parse_date` (терпит «21.04.2026г»), номера — `normalize_id`, числа частоты — `to_numeric(errors='coerce')` (нечисло → `NaN`). Номер строки Excel = индекс + 2.

### Пример
```python
records = MonitoringLabelsReader(c.labels).read()
records[0]   # row=2, скважина 16300, куст 1587, 12.10.2020 – 13.07.2021, частота 98.5 → 102.5 Гц
len(records) # 786
```

## MonitoringLabelsReader.rejection  [3ebb47e0]
Классовый метод: причина не брать запись, **видная без замеров**, либо `None`, если запись годится. Порядок проверок:

1. тип ГТМ не из `EVENT_TYPES` → «другой тип ГТМ»;
2. `success` не «да» → «неуспешное»;
3. статус не начинается с «выполнено» → «не выполнено»;
4. нет даты начала или окончания → «нет даты начала или окончания»;
5. окончание раньше начала → «окончание раньше начала»;
6. `new ≤ current` (или `NaN`) → «частота не увеличена (новое ≤ текущего)».

Проверка `not (new > current)` специально записана так, чтобы `NaN` тоже отбрасывался.

### Пример
```python
MonitoringLabelsReader.rejection(records[0])   # None: запись годится
```
На всём файле: 782 `None`, 3 «частота не увеличена», 1 «не выполнено». Остальные причины итогового отчёта (333 скважины нет в статистике, 153 нет замеров около начала, 89 частота не поднялась, 30 дубликатов) добавляет `dataset.py`.

## _text  [af2722cd]
Текст ячейки без пробелов по краям; `None` и `NaN` → пустая строка. Нужна, чтобы сравнения вроде `success.lower() != "да"` не падали на пустых ячейках.

### Пример
```python
_text("  да ")      # 'да'

```
