## @module  [f9251a7f]
Читатели статистики и разметки 2020–2026. Основной источник — **14 исходных полугодовых выгрузок** `resources/statistics/<год>/*.xls` (лист на параметр, строка — скважина, столбцы — даты полугодия): `HalfYearStatisticsReader`. Прежний источник — один склеенный `.xlsx` с теми же листами (`MergedStatisticsReader`, даты 01.01.2020–31.12.2026): его склеил макрос, и часть выгрузок в нём записана со сдвигом на 180 дней. Разметка технологов — `resources/labeled_data.xlsx` (лист «Лист1», строка — мероприятие, 786 строк): `MonitoringLabelsReader`.

Модуль данные **не исправляет**, а читает «как есть» (только числа): сдвиг склеенного файла чинит `repair.py` (и только для него — в полугодовых файлах сдвига нет). Результат работы модуля — таблицы «скважина × дата» и список `LabelRecord`, которые `dataset.py` превращает в `WellSeries`. `.xls` читается через `xlrd==2.0.2`, поток книги достаёт собственная `_workbook_stream`.

### Пример
```python
from gtm_detector.ml_freq.data import HalfYearStatisticsReader, MonitoringLabelsReader
tables = HalfYearStatisticsReader(c.statistics).read()   # 6 таблиц, частота: 616 скважин × 2498 дат
records = MonitoringLabelsReader(c.labels).read()        # 786 записей
```
В склеенном файле эти данные были сдвинуты: у скважины 10335/988 ступенька частоты 49,5 → 50,5 → 51,5 Гц стояла на 10.02.2024, а технолог ставил начало 14.08.2023 (ровно 180 дней разницы). В исходных полугодовых файлах подъём стоит на своём месте.

## MergedStatisticsReader  [f6d2b4a1]
Читает **склеенный** файл статистики (прежний источник; используется, если `statistics` указывает на файл `.xlsx`) в словарь `{параметр: DataFrame}`. Строки таблицы — `MultiIndex(номер, куст)`, столбцы — `Timestamp` с 01.01.2020 по 31.12.2026 (2557 дат), значения — `float`. В ячейке годится **только число**: текст, даты и `bool` становятся `NaN`. Пустые столбцы в формате даты (2020 г., конец 2026 г.) pandas читает как `NaT` — это тоже пропуски. Счётчик заполненных, но не числовых ячеек по датам хранится в `non_numeric`.

### Пример
Листы файла: «Qж (из OIS)», «Обв (из OIS)», «Qн (из OIS)», «Рлин (из OIS)», «Fэцн ТМ(сут)», «Рзаб». Словарь `SHEETS` ищет лист по началу имени, поэтому суффиксы «(из OIS)» и «(сут)» не мешают.

## MergedStatisticsReader.read  [26dcfdae]
Читает шесть листов (`debit_liquid`, `watercut`, `debit_oil`, `pressure_line`, `frequency`, `pressure_zab`). Лист подбирается по префиксу после `normalize_id`: так латинская «F» в имени листа не помешает найти «Fэцн ТМ(сут)». Складывает вклад каждого листа в `non_numeric` (сумма по листам) и пишет в лог число скважин и дат. Возвращает словарь таблиц.

Таблицы разных параметров могут содержать разные наборы скважин: выравнивает их потом `dataset.py`.

### Пример
```python
tables = reader.read()
{k: v.shape for k, v in tables.items()}
# frequency: (766, 2557); debit_liquid, watercut, pressure_line, pressure_zab: (768, 2557); debit_oil: (767, 2557)
```

## MergedStatisticsReader._read_sheet  [04818b43]
Читает один лист целиком (`header=None`). Строка `HEADER_ROW = 1` — названия столбцов, данные начинаются со строки 3 (`HEADER_ROW + 2`: одна строка под шапкой — подзаголовок). Столбцы с датой в заголовке (настоящей или строкой `ДД.ММ.ГГГГ`) превращаются в числовые колонки через `_numbers`; столбцы «№ скв.» и «№ куста» находит `_position` и нормализует `normalize_id`. Строки без номера скважины и повторы пропускаются.

Возвращает пару: таблицу значений и `Series` «сколько ячеек по датам было заполнено, но не числом» (нужна для отчёта аудита).

### Пример
Если бы в листе «Fэцн ТМ(сут)» в дату 14.08.2023 стоял текст (например «ремонт»), он стал бы `NaN`, а в `non_numeric` за эту дату прибавилась бы 1. В текущем файле таких ячеек нет: `non_numeric.sum() == 0`.

## HalfYearStatisticsReader  [1c090cba]
Читает **основной** источник статистики: папку `resources/statistics` с 14 исходными полугодовыми выгрузками `<год>/stats_by_first_half(…).xls` и `stats_by_second_half(…).xls` (годы 20–26, с 01.01.2020 по 02.11.2026). Результат такой же, как у `MergedStatisticsReader`: словарь `{параметр: DataFrame}`, строки — `MultiIndex(номер, куст)`, столбцы — непрерывный календарь, значения — `float`; поэтому `dataset.py` не видит разницы между источниками. Скважины — объединение по всем файлам (в 2020 г. их было меньше, чем в 2026).

Выгрузки исходные, не склеенные макросом: **сдвига на 180 дней в них нет**. Проверка по разметке без порога телеметрии: подъём частоты подтверждается у 427 мероприятий при сдвиге 0 и лишь у 79 при +180. Поэтому `BlockShiftRepair` для этого источника не запускается.

### Пример
```python
from gtm_detector.ml_freq.config import DataConfig
from gtm_detector.ml_freq.data import HalfYearStatisticsReader
reader = HalfYearStatisticsReader(DataConfig().statistics)   # resources/statistics
len(reader.files())                                          # 14
tables = reader.read()
tables["frequency"].shape                                    # (616, 2498): 01.01.2020 – 02.11.2026
```
Первое чтение 14 файлов занимает около трёх минут (результат потом лежит в кэше `dataset.py`).

## HalfYearStatisticsReader.read  [970e98ac]
Для каждого из 14 файлов: достаёт поток книги (`_workbook_stream`), открывает его в `xlrd`, по шести параметрам (`MergedStatisticsReader.SHEETS`) находит лист по префиксу имени (как у склеенного файла: «Fэцн ТМ(сут)» ищется по началу, латинская «F» не мешает) и переводит лист в таблицу (`_sheet_table`). Затем по каждому параметру склеивает таблицы периодов (`_join_periods`), суммирует нечисловые ячейки по датам в `non_numeric` и пишет в лог число файлов, скважин и дат. Если файлов нет, бросает `FileNotFoundError` — чтобы пустая папка не дала молча пустое обучение.

### Пример
```python
tables = reader.read()
{k: v.shape for k, v in tables.items()}   # все шесть: (616, 2498)
reader.non_numeric.sum()                  # 0: в полугодовых файлах нечисловых ячеек нет
```

## _workbook_stream  [40f675b1]
Достаёт из файла `.xls` (контейнер OLE2) поток `Workbook` — собственно книгу Excel — в виде `bytes`, **минуя разбор контейнера в `xlrd`**. Принимает путь, возвращает поток; если потока нет, `ValueError`.

**Зачем.** Прямой `xlrd.open_workbook(path)` на этих файлах падает с «size exceeds expected»: выгрузки сохранены не самим Excel, цепочка секторов потока длиннее размера, записанного в каталоге файла. Лишнее — только заполнение последних секторов, поэтому функция сама идёт по таблице размещения (FAT) до конца цепочки, не доверяя размеру, а `xlrd` получает готовый поток через `file_contents=`. Для больших файлов (больше 109 секторов таблицы) продолжение списка читается из отдельных секторов. Сверка с настоящим Excel: 504 случайные ячейки, расхождений 0.

### Пример
```python
from pathlib import Path
from gtm_detector.ml_freq.data.statistics import _workbook_stream
import xlrd
path = Path("resources/statistics/26/stats_by_first_half(01.01.2026-30.06.2026).xls")
book = xlrd.open_workbook(file_contents=_workbook_stream(path), on_demand=True)
book.sheet_names()[:2]   # листы параметров: «Qж (из OIS)», «Обв (из OIS)» …
```
Тест `test_workbook_stream_follows_chain_longer_than_declared` воспроизводит этот дефект на минимальном файле.

## _chain  [50537c62]
Номера секторов потока: от стартового сектора идёт по ссылкам таблицы `fat` (`fat[сектор]` — следующий), пока ссылка не отрицательная (-2 — конец цепочки). Принимает таблицу и стартовый номер, возвращает список номеров по порядку.

### Пример
Для таблицы `[-3, -2, 3, 4, -2]` цепочка от сектора 2 — `[2, 3, 4]`; от сектора 1 — `[1]`.

## _sheet_table  [30ebf1af]
Лист `xlrd` -> таблица «скважина × дата» плюс `Series` «сколько ячеек по датам заполнено, но не числом». Логика та же, что у `MergedStatisticsReader._read_sheet`: заголовок в строке `HEADER_ROW = 1`, данные с третьей строки, колонки «№ скв.» и «№ куста» ищет `_position`, колонки с датой — `_header_date`. Но тип ячейки берётся у `xlrd` (`row_types`), а не угадывается: числом считается только `XL_CELL_NUMBER`; пустая и «пробельная» ячейка — пропуск; текст, дата, ошибка — пропуск, который считается в `bad`. Строки без номера скважины (итоги) пропускаются, повтор скважины игнорируется (верна первая строка).

### Пример
Лист с датами 01.01.2021 и 02.01.2021: строка `["101", "5А", 48.0, "ремонт"]` даёт `48.0` и `NaN`, а в `bad` за 02.01.2021 прибавляется 1; пустая ячейка в `bad` не попадает. Это ровно сценарий `test_sheet_table_keeps_only_numbers`.

## _join_periods  [d06e5aeb]
Таблицы периодов -> одна таблица на непрерывном календаре. Склеивает столбцы (`concat(axis=1)`), скважины объединяются, нет скважины в файле — `NaN`. Если даты двух файлов налагаются, остаётся более поздний файл (`keep="last"`, файлы идут по порядку). Затем `reindex` на `date_range` от первой до последней даты: пропущенные дни становятся пустыми столбцами, а не исчезают — иначе окна «30 дней назад» в признаках считали бы пропуск как соседний день.

### Пример
Файл 1: 29.06.2021 и 30.06.2021; файл 2: 02.07.2021 (скважина 202 только в нём). Итог — четыре столбца с 29.06 по 02.07, 01.07 пуст у всех, у скважины 202 значения только в последнем. На реальных данных 14 таблиц дают 2498 столбцов (01.01.2020 – 02.11.2026).

Номер столбца (с нуля) в строке заголовков, где написано ровно `title` (после `strip`). Нужен, чтобы не зависеть от того, что «№ скв.» стоит в таком-то по счёту столбце. Если столбца нет — `StopIteration`.

## _numbers  [cfa0e563]
Превращает столбец листа в массив `float` длиной в число скважин. Если pandas определил столбец как `bool` или дату — весь столбец `NaN` (пустой столбец в формате даты читается как `NaT`). Если тип числовой — берётся как есть. Смешанный столбец (число, текст, дата) обрабатывается по ячейкам через `_number`.

### Пример
Столбец из `[48.0, 'ремонт', datetime(2023, 8, 14)]` даст `[48.0, nan, nan]`.

## _number  [b405b42b]
Одна ячейка: настоящее число (`int`/`float`, в том числе NumPy) → `float`; `bool`, текст, дата → `NaN`. `bool` отдельно отсекается, потому что в Python `True` — это число 1.

### Пример
```python

_number("49,5")  # nan  (текст не пытаемся разбирать)
_number(True)    # nan
```

## MonitoringLabelsReader  [3e23641f]
Читает «Лист1» итогового файла: сводный список всех мероприятий. «Лист2» намеренно не читается: это частичная копия 2025 г., а строки, которых нет в «Лист1», — тип «Изменение ЦЭС/Частоты на увеличение», который технологи в сводный список не включили. `COLUMNS` — отображение заголовков Excel («Куст», «Скважина», «Тип ГТМ», «Статус ГТМ», «Успешно/Неуспешно», «Причина прекращения мониторинга», «дата начала мониторинга», «дата окончания мониторинга», «Текущее значение», «Новое значение», «Год») на поля `LabelRecord`. `EVENT_TYPES` — подходящие типы: «изменение частоты, гц» и «увеличение f».

## MonitoringLabelsReader.rejection  [3ebb47e0]
Классовый метод: причина не брать запись, **видная без замеров**, либо `None`, если запись годится. Порядок проверок:

1. тип ГТМ не из `EVENT_TYPES` → «другой тип ГТМ»;
2. `success` не «да» → «неуспешное»;
3. статус не начинается с «выполнено» → «не выполнено»;
4. нет даты начала или окончания → «нет даты начала или окончания»;
5. окончание раньше начала → «окончание раньше начала»;
6. `new ≤ current` (или `NaN`) → «частота не увеличена (новое ≤ текущего)».

Проверка `not (new > current)` специально записана так, чтобы `NaN` тоже отбрасывался.

### Пример
```python
MonitoringLabelsReader.rejection(records[0])   # None: запись годится
```
На всём файле: 782 `None`, 3 «частота не увеличена», 1 «не выполнено». Остальные причины итогового отчёта (на полугодовых данных: 313 частота не поднялась, 40 дубликатов, 5 нет телеметрии) добавляет `dataset.py`.

## _text  [af2722cd]
