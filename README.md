# gtm_detector/ml_freq

3) ML-подход для ГТМ `увеличение частоты F`: собственная нейросеть
(Transformer-энкодер для временных рядов, PyTorch) и готовые модели
scikit-learn (логистическая регрессия, случайный лес, Extra Trees,
градиентный бустинг). Все модели для каждого дня оценивают вероятность эффекта
мероприятия, из неё получаются даты начала и окончания; качество сравнивается
перекрёстной проверкой по скважинам.

Запуск из корня проекта:

```bash
python -m gtm_detector.ml_freq compare                      # сравнить все модели
python -m gtm_detector.ml_freq train --model gboost         # обучить и сохранить
python -m gtm_detector.ml_freq predict --model gboost       # найти мероприятия
python -m gtm_detector.ml_freq audit                        # отчёт о качестве данных 2020–2026
```

По умолчанию модели учатся на 14 исходных полугодовых выгрузках
`resources/statistics/<год>/*.xls` (2020–2026, 616 скважин) и разметке
`resources/labeled_data.xlsx`: в обучение попадает 424 мероприятия на 369 скважинах.
Сдвига на 180 дней в этих файлах нет (он был в прежнем склеенном файле и исправляется
только при его чтении). Лучший результат у градиентного бустинга: найдено 74 %
размеченных мероприятий, дата начала ±3 дня — 89 %. Детектор на правилах
(ветка `feature/increase-f-gtm`) пока не превзойдён. Подробности, таблицы до и после
и оговорки о сравнимости метрик — в `gtm_detector/ml_freq/README.md`.

Подробности и результаты - в `gtm_detector/ml_freq/README.md`. Разбор каждого класса,
функции и метода с примерами из проекта — в `gtm_detector/ml_freq/Построчный_разбор_ml_freq.pdf`
(собирается из кода: `python -X utf8 docs/ml_freq_walkthrough/build.py`).

# dirs

`constants`:
- `path.py`: хранит класс констр.переменн (url, пути к сохр и тд)

`helpers`:
- `converter.py`: вспомогательный класс для конвертации (не использовал)
- `time.py`: статичный класс для работы со временем; создаёт папки по датам

`resources` (только чтение, папка скрыта от Git):
- `statistics/<год>/*.xls`: исходные полугодовые выгрузки замеров (20–26 годы, 14 файлов)
- `labeled_data.xlsx`: разметка технологов (786 строк).
`results`: 
- `success_and_has_dates.csv`: Файлик с отфильтрованными скважинами (
но не только с `увеличением F`).

- `success_and_has_dates/`
    `all_gtms`: Все виды ГТМ с первоначального файлика Рината,
    которые успешны и имеют обе даты.
    `increase_f_gtm`: Только ГТМ с увеличением F
