
## test_datas

В этой директории хранится самые первые тестовые данные
для скважин.

`input_dataset.xlsx` - статистика замеров за 2025 год.
`outout_dataset.xlsm` - разметка технологов.  

`Итоговый_файл_с_2021_2026.xlsx` - разметка технологов за период 2021 по 2025 год. 

`Статистика_с_2021_2026_в_одном_файле.xlsx` - статистика за 2021 по 2026 год, собранное все в одном файле.

`Статистика_2021-2026.rar` - архив статистик (не использовать при обучении)
